# Study Notes

This folder contains a professional, structured guide for the repository. The documentation is organized by learning path so you can move from fundamentals to advanced deep learning without losing the conceptual flow.

## Main study paths

- [Python for ML](./python-for-ml/README.md)
- [Machine Learning](./machine-learning/README.md)
- [Deep Learning](./deep-learning/README.md)
- [Advanced Deep Learning](./advanced-deep-learning/README.md)

## How to use this folder

1. Start with Python for ML
2. Move to Machine Learning fundamentals
3. Then study Deep Learning
4. Finish with Advanced Deep Learning and modern NLP architectures

Each section follows the same learning structure:

- concept
- intuition
- math
- architecture
- code pattern
- interview answer
- pitfalls
- takeaways

This is designed to help you study and revise quickly before interviews, exams, or project work.
