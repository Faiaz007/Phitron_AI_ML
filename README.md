## Interview-ready core concepts

### Machine Learning essentials
- Linear regression: minimizing squared error for continuous targets
- Logistic regression: probability estimation for classification
- Decision trees: splitting on feature conditions to reduce impurity
- Random forest: ensemble of decorrelated trees
- Boosting: improving models by focusing on residual errors
- KMeans: clustering by centroid minimization
- PCA: reducing dimensionality by preserving maximum variance

### Deep Learning essentials
- Perceptron: the simplest trainable decision unit
- Activation functions: introduce nonlinearity
- Backpropagation: propagate gradients via the chain rule
- Gradient descent: update weights toward lower loss
- Dataloaders: deliver batched, efficient training input
- Autograd: compute gradients automatically

### Advanced DL essentials
- RNN: process ordered inputs through hidden states
- LSTM: gated memory for long-range dependency capture
- GRU: simplified memory gate design
- Attention: focus on relevant tokens or features
- Transformer: parallel attention-based sequence processing
- NLP tasks: classification, translation, summarization, and QA

## Quick study method

For every notebook in this repo, use this loop:

1. Read the concept statement
2. Understand the intuition
3. Write the core equation
4. Reimplement the pattern in code
5. Explain the result in interview language

This helps convert memorization into understanding.
